# Briefy

用 AI 自动填充内容，像排报纸一样制作个性化读物的桌面应用。

## 定位

**"内容规划"与"内容生成"彻底分离**——用户只负责布局和意图（框选区块、写提示词），AI 负责填充和呈现。所见即所得的 A4 版面，一键生成、导出 PDF。

## 技术栈

- Electron + React + TypeScript
- AI 编排：Vercel AI SDK（OpenAI 兼容接口）
- 设计文件：`.briefy`（JSON 格式）

## 开发

```bash
npm install   # 建议使用 npmmirror 镜像
npm run dev
```
